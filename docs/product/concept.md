# プロダクト定義書

## 概要

| 項目             | 内容                                                             |
| ---------------- | ---------------------------------------------------------------- |
| **プロダクト名** | Escape Map（仮称）                                               |
| **目的**         | 今が苦しいときに、落ち着ける場所や相談先が見つけられるサービス。 |
| **対象ユーザー** | 苦しさや生きづらさを感じている10代後半〜20代の若者。             |
| **中心機能**     | 逃げ場所マップ、相談文メーカー、相談窓口                         |

## コンセプト

今が苦しい/生きづらいと感じている若者に向けて、落ち着ける場所、誰かに送る一文、必要に応じた相談窓口への導線を提供するサービス。

## ビジョン

今が苦しい/生きづらいと感じている若者が、少しだけ自分を守る選択肢を持てるようになる。

本プロダクトが目指すのは、負の感情を診断・治療したり、解決したりすることではない。
苦しさや生きづらさを感じているとき、場所を変える、誰かに伝える、相談先を見るという小さな選択肢を提示し、ユーザーが自身で次の行動を選べる状態をつくることである。

## ターゲットペルソナ定義

### 基本属性

- **年齢**：10代後半〜20代の若者
- **属性**：上記年齢に当てはまる若者（高校生、大学生、専門学生、アルバイトをしている若者、新卒1〜2年目の社会人など）
- **その他**：PCやスマホで本プロダクトを使用できる状態にあること

### 心理・行動特性

- **心理状態**
  - 家にいたくない
  - 人間関係などで学校・会社にいたくない
  - 落ち着ける場所を知りたい
  - 誰かに今の状況を相談したり話を聞いたりして欲しい
  - どこにどうやって相談したらいいか分からない

- **行動傾向**
  - 家や学校・会社から離れたいが、行き先がなくて動けない
  - Google Mapsなどで場所を探そうとするが、どのように検索すればいいか分からない
  - 誰かに相談しようとするが、どのように相談すればいいか分からずにやめる
  - 持っている選択肢ではどうすることもできずに諦める

## コンテンツ

本プロダクトの中心コンテンツは、以下の3つである。

1. 逃げ場所マップ
  - 今いる場所から少し離れたいと感じたときに、近くの落ち着ける可能性のある場所を見つけられるようにする。
  - カテゴリではなく、「一人になりたい」「人目がある場所にいたい」「静かな場所がいい」「お金を使いたくない」など、ユーザーの状態や条件から探せるようにする。

2. 相談文メーカー
  - 誰かに相談したいが、うまく言葉や文章にできないユーザーに向けて、最低限の状況や希望を伝えられるような文を提供する。
  - 友達、家族、先生、上司、相談窓口など、相手に応じた文面を用意する。

3. 相談窓口
  - 相談先が分からないユーザーに、外部の相談窓口へつなぐ。
  - つらさが強いときや、一人で抱えることが難しいときに、本プロダクト内だけで完結させず、外部の相談先・支援先へ進めるための安全導線として扱う。

## 目指さないこと

- 診断・治療・カウンセリングの代替
- 悩みの根本解決
- 行動を強制すること
- ユーザー同士の交流
- ポジティブや回復の押し付け
- 危機状態をサービス内だけで抱え込むこと
